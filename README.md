# Academic homepage

This repository is a minimal GitHub Pages site for an academic homepage.

## Content model

- Edit [_data/profile.yml](_data/profile.yml) for the author bio and contact links.
- Edit [_data/publications.yml](_data/publications.yml) for the publication list.
- Edit [_data/teaching.yml](_data/teaching.yml) for teaching experience.
- Edit [_data/blogposts.yml](_data/blogposts.yml) for the homepage blog list.
- Add internal posts in [_posts](_posts) to host writing on this site.
- Place downloadable PDFs and similar assets in [files](files).

## Local build

Use Jekyll with GitHub Pages dependencies:

```bash
bundle install
bundle exec jekyll serve
```
